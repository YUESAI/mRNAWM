# Data Plan for Codon-Level World Model

## Goal

Build normalized records for antigen-conditioned mRNA design:

```text
protein_sequence, orf_sequence, utr5_sequence, utr3_sequence, metadata
```

The first model version should focus on ORF/codon design. UTRs are preserved as
fields but can initially be used for retrieval or downstream predictors rather
than direct generation.

## Data Sources

### General Protein-ORF Pretraining

Use structured transcript/CDS data rather than keyword search.

- RefSeq transcript/protein records from local FTP or NCBI Datasets exports.
- Ensembl transcript/CDS/protein records by species.
- Optional pathogen records from NCBI Virus, BV-BRC, or GenBank subsets.

These records train the model to understand codon-level sequence design and
host/source-specific codon distributions. They do not by themselves define
vaccine antigen quality.

### Antigen Annotation and Fine-Tuning

Antigen labels should come from protein/epitope annotation sources:

- IEDB antigen/epitope records.
- UniProtKB function, taxonomy, disease, and cross-reference metadata.
- NCBI Virus or BV-BRC pathogen metadata.

These annotations can be joined to normalized protein records by accession,
taxonomy, exact protein sequence, or clustered protein identity.

### UTR Data

UTR records should be split and preserved, but first-generation generation can
use template retrieval:

- high-expression 5'UTR templates
- stable 3'UTR templates
- natural UTRs from high-confidence transcript datasets

Direct UTR generation should be a later module because UTR length and function
are weakly constrained relative to ORF codon design.

## Normalization Rules

1. Convert RNA `U` to DNA `T` internally.
2. Store ORF/CDS separately from 5'UTR and 3'UTR.
3. Validate ORF translation against the protein sequence.
4. Preserve source database, source accession, transcript ID, protein ID,
   taxonomy ID, organism, and feature coordinates.
5. Mark antigen/disease/pathogen metadata as annotation, not as sequence truth.
6. Prefer taxonomy ID filters over keyword filters.

## Leakage Control

Dataset splits should not be random rows.

1. Exact-deduplicate by protein sequence, ORF sequence, transcript accession,
   and protein accession.
2. Cluster protein sequences with MMseqs2 or CD-HIT.
3. Assign whole clusters to train/validation/test.
4. Keep records from different databases in the same cluster together.
5. For antigen evaluation, also consider pathogen/species/protein-family
   holdout splits.

## World-Model Training Records

For each completed ORF candidate `x_1:T`, the environment produces reward vector
`R(x)`.

The world model consumes prefix-action examples:

```text
protein_sequence, prefix_codons, candidate_codon, reward_weights, final_reward_vector
```

Counterfactual probes are generated by replacing a codon with another legal
synonymous codon, completing the suffix, and rescoring the full candidate. These
examples teach the model action consequences, not only next-codon likelihood.
